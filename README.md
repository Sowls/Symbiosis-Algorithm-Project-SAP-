# Symbiosis-Algorithm-Project-SAP-
Je me suis lancé un défi il y a 6 mois : créer un « laboratoire spéculatif » sur Discord faisant s'affronter une centaine de robots aux stratégies variées (RSI, MACD...) sur 6 marchés (Crypto et Matières Premières).  Avec une première version déjà rentable,je mets à jour régulièrement l'algorithme pour créer un véritable assistant pour les traders.
